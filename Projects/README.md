# AURA Demo Projects

Demo `.aura` projects ship here in Phase 2:

- `Demo Song.aura` — full mix showcasing EQ, dynamics, AURA Synth
- `Beat Starter.aura` — 8-bar hip-hop template with sampled drums
- `EDM Template.aura` — side-chained supersaw starter

Autosaves are written to `Projects/autosave/` (git-ignored).
