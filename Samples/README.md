# AURA Factory Sound Library

Ships with the installer under `Factory Library/`.

Phase 1 contains the folder structure only. Phase 3 adds:

- `Drums/` — 200 one-shots (kick, snare, hats, percussion), 24-bit WAV
- `Loops/` — 100 tempo-tagged loops (80–140 BPM)
- `Instruments/` — multi-sampled keys, bass, pads for AURA Sampler
- `IR/` — convolution reverb impulses (Phase 3)

All factory content is royalty-free for music produced with AURA DAW.
